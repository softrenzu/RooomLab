# RooomLab

Version: `0.1.0`

Reproducible reactive Python cell engine with dependency analysis, deterministic execution order, stale-cell propagation, and serializable notebooks.

## Status

This is a working early core, not a claim of feature parity or production superiority over marimo. The goal is to establish an independently maintainable ROOOMTECH codebase with enterprise controls added deliberately.

## Quick start

Requires Python 3.11+.

```bash
python -m unittest discover -s tests -v
```
